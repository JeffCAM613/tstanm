## The coverage check

Three layers, all reading the same inventory:

| Layer | Script | Answers |
|---|---|---|
| Before | `run_op_anonymization.bat /dryrun` | Does every column resolve? Do generated codes fit? How many rows would change? |
| Before | `tools/analyze_flag_impact.sql` | Which columns does each flag actually govern here? What is unmapped? |
| After | `op/verify/verify_op_coverage.sql` | **Does any original value survive anywhere?** |

The verifier's primary test is residual detection — is any value still present that appears in the
mapping as an original? That has a definite answer and cannot be fooled by a coincidental prefix,
which is how v3's check produced false passes.
